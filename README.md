# NuxVisuals

Клиентский Fabric-мод для Minecraft 1.21.4. Проект использует Java 21. Это исходный код, не готовый JAR и не подтверждение одобрения модерацией HolyWorld.

## Сборка

Установите JDK 21, затем выполните `./gradlew build` (Windows: `gradlew.bat build`). Результат Gradle будет в `build/libs/`.

## Перед публикацией / отправкой на проверку

- Этот проект содержит как визуальные модули, так и автоматизацию игровых действий. См. полный перечень в `APPROVAL.md`.
- В предоставленном исходном архиве интеграция HolyWorld LiteAPI не обнаружена. Не заявляйте о совместимости до реализации и проверки.
- В архив не включены локальная папка игры, сохранения, логи, собранные классы и история Git.
- Публикация исходников сама по себе не означает одобрение мода сервером.
